# Finatic demo apps

Demo applications for **FinaticClientSDK**, **FinaticServerSDK-Node**, and **FinaticServerSDK-Python**, grouped under one repository.

| Path | Description |
|------|-------------|
| `client/` | Browser / Vite client demos |
| `server-node/` | Node server demos |
| `server-python/` | Python server demos |

From the Finatic devcontainer, run orchestrator demo commands (see root orchestrator docs) or follow each subfolder’s README after installing dependencies.
